        How to patch
        
    
          
  • Add a node: double-click the grid, press Tab, or drop a cable on empty space.
    • 
          
  • Patch: drag from a jack to a jack.  image cables go into image inputs,  control cables into any slider.
    • 
          
  • A patched slider gets a mod depth: how far the cable pushes it from where you set it.
    • 
          
  • Unplug: drag a cable off its input, double-click it, or ⌥-click it.
    • 
          
  • Space play · ⌫ delete · ⌘D duplicate · ⌘Z undo · F frame all · scroll pans, pinch / ⌘-scroll zooms.
    • 
          
  • Double-click a node title to see its GLSL. Fork any node to edit it live.
